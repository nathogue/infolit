Welcome to Christian Leader's Institute's Information Literacy Tutorial. Research is more than finding information. It is a process of asking useful questions, searching strategically, evaluating evidence, using sources responsibly, and communicating what you learn. This tutorial introduces practical information-literacy skills that you can apply to academic assignments, ministry research, professional questions, and lifelong learning.The goal of this tutorial is to assist you with the ability to identify the different roles information may play. You will be introduced to topics related to the location, evaluation, selection, and use of information sources, ethical source integration and citation management. Through critical thinking applications and practicing evaluation, use, and creation of information, this tutorial should get you started in helping you succeed in your coursework and assignments.

The tutorial is self-paced. Move through the modules in order when possible because later modules build on skills introduced earlier. Read the explanations, study the examples and visuals, and use the downloadable handouts in the last lessons in each module to apply the ideas to your own research.  Each module ends with one short wrap-up quiz. The practice prompts are ungraded. If you do not get an answer correct, simply review the relevant section and try again by clicking the "reset" button. 

Each self-paced module can be completed in 10-15 minutes.

How to Use Feedback
Quiz feedback is part of the learning process. A wrong answer is a signal to revisit the concept, not a penalty. Use the feedback, review the relevant explanation or example, and retry the wrap-up quiz when you are ready.
